## 1. Governance & Verification Rules

1. **Unknown Values:** `null` or unverified status means unverified; never infer a production status, client delivery, or ownership bucket.
2. **Publication Rights:** Require explicit owner-approved attribution, status confirmation, content clearance, and written display permission before promoting any project to a completed public client case study.
3. **MOTEKRA Engagement:** MOTEKRA client engagement is only asserted when explicitly established by commercial agreement.
4. **Independent Work:** Personal or founder-independent work must never be presented as a MOTEKRA client engagement.
5. **Collaborative Work:** Credit actual contribution; never imply sole ownership.
6. **Concept Work:** Must be explicitly labeled as a concept or design exploration; interface figures and sample metrics must not be represented as production results.
